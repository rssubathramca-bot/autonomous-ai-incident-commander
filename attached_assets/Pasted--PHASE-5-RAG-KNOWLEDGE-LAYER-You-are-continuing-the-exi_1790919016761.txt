# OBJECTIVE OF PHASE 5

Build the **RAG + Knowledge Layer**.

The purpose of this phase is to give the Incident Commander access to approved operational knowledge that can later be used by the AI reasoning layer.

The Phase 5 pipeline must be:

```text
Knowledge Documents
        ↓
Document Loading
        ↓
Document Chunking
        ↓
Embeddings
        ↓
Vector Index
        ↓
Similarity Search
        ↓
Top-K Relevant Evidence
```

Phase 5 must **NOT** perform root-cause reasoning.

Phase 5 must **NOT** make remediation decisions.

Phase 5 must **NOT** automatically execute actions.

---

# VECTOR SEARCH

Implement actual semantic vector retrieval.

The system must:

1. Load documents.
2. Chunk documents.
3. Generate embeddings.
4. Store/index the vectors.
5. Accept a search query.
6. Generate the query embedding.
7. Calculate similarity against indexed chunks.
8. Sort results by similarity.
9. Return the top-K results.

Do NOT simply search for hard-coded keywords.

Do NOT hard-code:

```text
database timeout → INC-873
```

The result must come from the actual retrieval process.
