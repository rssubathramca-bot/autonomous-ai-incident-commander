IMPORTANT SAFETY RULE
=====================

The AI must NEVER directly execute dangerous or consequential production actions.

Default mode:
READ-ONLY INVESTIGATION

Remediation must follow:

Recommendation
→ Risk Assessment
→ Human Approval
→ Allowlist Check
→ Simulation
→ Controlled Execution
→ Validation
→ Audit Log

For the hackathon MVP, all remediation should operate against the simulated environment only.

==================================================
AI USAGE LIMIT
==============

Do not use an LLM for tasks that can be solved deterministically.

Use normal Python code for:

* database operations
* CRUD operations
* incident state management
* severity calculations
* metric calculations
* threshold detection
* timestamp handling
* log parsing
* API validation
* authentication/authorization logic
* audit logging
* remediation allowlist validation
* recovery calculations
* deterministic business rules

Use AI only where reasoning or language understanding provides real value:

1. Log pattern interpretation
2. Operational document understanding
3. RAG question answering
4. Evidence summarization
5. Root-cause hypothesis generation
6. Remediation explanation/recommendation
7. Postmortem generation

Do not send the entire database or all logs to the LLM.

Retrieve and send only relevant evidence.

Every AI response must contain structured output.

Prefer JSON/Pydantic schemas over free-form text.

==================================================
AI OUTPUT REQUIREMENTS
======================

AI responses must never be treated as automatically correct.

Every root-cause result must include:

{
"hypothesis": "...",
"confidence": 0,
"supporting_evidence": [],
"contradicting_evidence": [],
"reasoning_summary": "...",
"recommended_next_check": "..."
}

Confidence must be clearly labeled as an AI-generated confidence estimate, not a guaranteed probability.

==================================================
EVIDENCE CHAIN

Every important AI conclusion must reference evidence.

Evidence may come from:

* application logs
* metrics

Do not allow the AI to invent evidence.

If sufficient evidence is unavailable, explicitly return:

INSUFFICIENT_EVIDENCE
